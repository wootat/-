카페를 열기 위해 모으는 노트 — 로스팅, 브루잉, 에스프레소 전문 지식부터 쌓는다.

1. 로스팅 프로파일 2. 브루잉 레시피 3. 에스프레소·원두 전문 지식

1. 로스팅 프로파일

로스팅 한 번마다 카드 하나씩 추가한다. 매번 같은 항목으로 적는다.

작성 예시: 에티오피아 (예시 카드)

  • 날짜: 2026-11-03
  • 원두: 에티오피아 / 워시드
  • 생두 무게: 500g
  • 투입 온도: 200°C
  • 1차 크랙: 8분 30초 / 196°C
  • 배출: 10분 20초 / 205°C
  • DTR: 약 18% (1분 50초 ÷ 10분 20초)
  • 볶은 뒤 무게: 425g / 감소율 15%
  • 맛 평가: 단맛이 잘 나고, 끝맛이 깔끔했다
  • 다음에 바꿀 점: 산미를 조금 더 살리고 싶으면 배출을 10초 늦춰보기

2. 브루잉 레시피

드리퍼, 무게, 물량, 시간, 붓는 순서를 초 단위까지 적는다.

V60 핸드드립

  • 드리퍼: V60 / 종이 필터
  • 원두: 20g / 분쇄도: 중간에서 조금 가는 정도
  • 물: 320g / 비율 1:16 / 온도 93°C

붓는 순서

  1. 0:00 — 40g 붓고 0:40까지 뜸들이기
  2. 그다음 — 200g까지 붓기
  3. 1:15 — 320g까지 완성하기
  4. 2:45~3:30 — 물이 다 빠지면 끝

맛 평가: (마셔본 뒤 적기) / 다음에 조절할 점: (한 가지씩만 바꾸기)

3. 에스프레소·원두 전문 지식

추출 비율과 원두 특성에 따른 조절법을 쌓는 곳이다.

에스프레소 기본 추출

  • 더블샷: 원두 18~20g → 추출량 36~40g
  • 시간: 25~30초 / 압력: 9bar / 온도: 92~94°C

음료 비율표

  • 카푸치노: 에스프레소 : 스팀밀크 : 거품 = 1 : 1 : 1
  • 카페라떼: 에스프레소 : 스팀밀크 = 1 : 3~4
  • 아메리카노: 에스프레소 + 뜨거운 물

원두 특성에 따른 추출 조절

  • 밝게 볘은 원두: 물 온도를 조금 높이고, 추출을 조금 길게 — 산미와 향을 더 끌어낸다
  • 진하게 볶은 원두: 물 온도를 조금 낮추고, 추출을 조금 짧게 — 쓴맛이 과해지는 걸 막는다
  • 원칙: 한 번에 한 가지 변수만 바꾼다. 그래야 뭐가 달라졌는지 알 수 있다
